## Interaction Test/Guide

### Steps to Play the Program

1. **Player chooses right path:**  
   - Input: `2`

2. **Player inputs name:**  
   - Input: `nat`

3. **Player navigates forest maze:**  
   - Input sequence: `1, 1, 3, 3, 4, 4, 1`

4. **Player chooses to enter dungeon:**  
   - Input: `1`

5. **Floor 1, Room 1: Pick up Small Health Potion:**  
   - Input: `1`

6. **View inventory:**  
   - Input: `2`

7. **Move to next room:**  
   - Input: `1`

8. **Floor 1, Room 2: Pick up Rusty Dagger:**  
   - Input: `1`

9. **Move to next room:**  
   - Input: `1`

10. **Floor 1, Room 3: Move to next room:**  
    - Input: `1`

11. **Floor 1, Room 4: Pick up Medium Health Potion:**  
    - Input: `1`

12. **Check status:**  
    - Input: `3`

13. **Move to next room:**  
    - Input: `1`

14. **Floor 1, Room 5: View inventory:**  
    - Input: `2`
